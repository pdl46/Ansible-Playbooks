# Ansible-Playbooks
A collection of Ansible playbooks for automating Linux infrastructure configuration, service management, and system hardening. This repository consists of 

- Playbook directory
- ansible.cfg file
- inventory file 
- jinja file
- .gitignore file

This repository consists of the following sub-directories:

1. web-server-set-up

- consists of webdeploy.yml
- webdeploy.yml installs httpd package, start and enable httpd service, enable firewall for the httpd service, and copy index.html file to the WebServ  er/n
