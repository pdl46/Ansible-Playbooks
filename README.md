# Ansible-Playbooks
A collection of Ansible playbooks for automating Linux infrastructure configuration, service management, and system hardening. This repository consists of Playbook directory, ansible.cfg file, and inventory file required to run ansible Playbooks.

Playbook directory consists of multiple sub-directories:

1. web-server-set-up
This directory consists of webdeploy.yml.\n
webdeploy.yml installs httpd package, start and enable httpd service, enable firewall for the httpd service, and copy index.html file to the WebServer/n
